## Why this exists

AI tools write code quickly, but the output often goes in without a careful second look. Revalidate AI acts as that second pair of eyes: you describe what you were trying to build, paste the code the AI produced, and get a structured review from the perspective of a developer with 20+ years of experience.

## How it works

1. Open the review page and describe your **project goal** and the **original prompt** you gave the AI.
2. Pick the **language or framework** and paste the **AI-generated code**.
3. Optionally add **specific concerns** and choose the **feedback areas** you care about (for example security or performance).
4. The app sends this to a Next.js API route, which asks Llama 3.3 70B on Groq (through the Vercel AI SDK) to review the code and returns detailed, actionable feedback.

## Tech stack

- **Framework:** Next.js 15 (App Router), React 19, TypeScript
- **UI:** Tailwind CSS, shadcn/ui (Radix UI)
- **AI:** Vercel AI SDK with the Groq provider (`llama-3.3-70b-versatile`)
- **Hosting:** Vercel

## Getting started

Requires Node.js 18+ and [pnpm](https://pnpm.io/).

```bash
git clone https://github.com/Ro-hit-Sonar/Revaildate-AI.git
cd Revaildate-AI
pnpm install
```

Create a `.env.local` file:

```bash
# Groq API key (https://console.groq.com)
GROQ_API_KEY=your_groq_api_key

# Credentials for the demo login page
NEXT_PUBLIC_ADMIN_EMAIL=you@example.com
NEXT_PUBLIC_ADMIN_PASSWORD=choose_a_demo_password
```

Then start the dev server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

```
app/
  page.tsx              Landing page
  review/page.tsx       Code review form and results
  login/page.tsx        Demo login
  about/page.tsx        About page
  api/review/route.ts   POST endpoint that calls Groq and returns the review
components/             Shared UI (shadcn/ui)
```

## Notes

- The login is a **demo-only gate**. Its credentials come from `NEXT_PUBLIC_` variables, which are exposed to the browser, so do not reuse a real password and do not treat it as production authentication.
- Reviews are generated by a language model and can be wrong. Treat them as a helpful second opinion, not a replacement for human review and tests.
